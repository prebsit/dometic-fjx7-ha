## Findings
- BLE at ESPHome 2026.9's default 100% scan duty starves the setup hotspot:
  phones see it but can't finish the WPA2 handshake. Fix: BLE off until
  first WiFi join (packages/provisioning.yaml).
- Captive portal logs the user's WiFi password at INFO. Shipped firmware
  should run the logger at WARN.
- iCloud Keychain syncs hotspot passwords between Apple devices: forget the
  network on ALL devices before testing a typed join.
- Hotspot twice invisible to phone while the chip reported it broadcasting;
  cleared by a board reset. Not reproduced since. Setup card should say
  "can't see it? unplug for 5 s".
- This board reads -81 to -90 dBm at 1 m from the router (van bridge, same
  model, gets -62 to -72 from a cupboard). Suspect antenna/batch. TODO:
  compare with another SuperMini, and out of the case.
